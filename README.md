# 🚇 Underground RP — Loading Screen

Кастомный загрузочный экран для сервера **Underground RP** (DarkRP, Garry's Mod).

---

## 📁 Структура

```
loading/
├── loading.html       ← главный файл загрузочного экрана
└── (все остальные файлы из оригинального архива)
```

> Фоновое изображение и логотип **встроены прямо в `loading.html`** в формате base64 — дополнительные файлы изображений не нужны.

---

## ⚙️ Установка

1. Скопируй `loading.html` в папку загрузочного экрана на сервере:
   ```
   garrysmod/lua/includes/modules/loadingscreen/
   ```
   или в папку аддона, если используется кастомный аддон загрузочного экрана.

2. В `server.cfg` укажи адрес загрузочного экрана:
   ```
   sv_loadingurl "http://ВАШ_САЙТ/loading/loading.html"
   ```
   Либо используй локальный файл через аддон.

## 🎨 Что внутри

| Элемент | Описание |
|---|---|
| **Фон** | Скриншот карты бункера, затемнённый + сканлайны + виньетка |
| **Логотип (центр)** | Логотип Underground RP с пульсирующим красным свечением |
| **Шапка (лево)** | Логотип + название сервера + подзаголовок |
| **Статусы (право)** | Индикаторы систем сервера + часы реального времени |
| **Лог загрузки (низ)** | Строки загрузки с анимацией появления |
| **Инфо сервера (низ право)** | Название, карта, режим — появляются после коннекта |
| **Рамка** | Тонкая рамка по краям с угловыми маркерами |

## 🔧 GMod API

Загрузочный экран поддерживает стандартные функции GMod:

```javascript
// Вызывается при подключении к серверу
GameDetails(servername, serverurl, mapname, maxplayers, steamid, gamemode, volume, lang, gamemodeNice)

// Вызывается при загрузке файла
DownloadingFile(filename)

// Вызывается при смене статуса загрузки
SetStatusChanged(status)
```

## ✏️ Кастомизация

### Поменять фоновое изображение
Заменить base64-строку внутри `#bg` в CSS:
```css
#bg {
    background: url('data:image/jpeg;base64,ВАША_СТРОКА') center/cover no-repeat;
}
```
Конвертировать: `base64 -i image.jpg | tr -d '\n'`

### Поменять логотип
Найти все вхождения `data:image/png;base64,` и заменить строку на новую.

### Поменять цвета
В начале CSS в блоке `:root`:
```css
:root {
    --red:   #c0392b;   /* основной акцент */
    --red2:  #e74c3c;   /* яркий красный */
    --amber: #e67e22;   /* оранжевый */
}
```

### Поменять тексты статусов в логе
В JS-массиве `bootLog` — список строк, которые появляются при загрузке.
